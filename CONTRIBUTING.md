# Contributing to AgentOps.NET

Thanks for considering contributing.

## Issues
Issue templates coming soon. For now, please describe:
- What you tried
- What you expected
- What happened instead

## Pull requests
- One concern per PR
- Include or update tests when changing behavior
- Update relevant ADRs in `docs/decisions/` when changing public API surface

## Code of Conduct
This project follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

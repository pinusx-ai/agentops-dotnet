# AgentOps.Mcp.Hardening

Runaway prevention for Microsoft Agent Framework — bounded tool calls, recursion depth, and token budgets via Agent, Function, and Chat middleware layers.

> ⚠️ **v0.1-alpha:** API surface is in active development. Public types may change before 1.0.

Part of [AgentOps.NET](https://github.com/pinusx-ai/agentops-dotnet) — the reference architecture and library suite for putting Microsoft Agent Framework + MCP into production on Azure.

## Install

```bash
dotnet add package AgentOps.Mcp.Hardening --prerelease
```
